Architecture Overview

Trader — Systematic Swing Trading System

A Python command center for Stage 2 momentum trading. Scans markets, curates a tiered watchlist, generates pre/post-market reports, and executes entries and exits automatically through Alpaca — all driven by a shared scoring and risk-sizing core.

Layer 4 — Automated Trading Engine (Alpaca)

Paper Engine

paper_engine_alpaca.py

Main event loop. Streams WebSocket prices, evaluates entry rules against traderlib, and orchestrates the state, exits, and order modules.

Orchestrator

Alpaca Client

alpaca_client.py

REST + WebSocket wrapper with rate-limited requests and health monitoring. Handles auth, quotes, positions, and orders.

Order Manager

order_manager.py

Tracks order lifecycle (submit → fill → close), normalizes statuses, and surfaces partial fills back to the engine.

Exit Engine

paper_exits.py

R-multiple trailing logic: +1R → breakeven, +1.5–2R → EMA10, +3R+ → EMA21, hard stop at 2×ATR, targets at ≥ 2R.

Entry GateScore ≥ 60 · ±1% of pivot · vol ≥ 1.5× · SPY ≥ −0.3%
Position Size0.75% risk · < 20% equity · max 3/sector
Circuit Breakers≤ 5 entries/day · halt if day P&L < −2%
Exit LadderBE → EMA10 → EMA21 · hard stop 2×ATR
